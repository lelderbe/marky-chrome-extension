# Позиционирование Marky

**Обещание:** сохраняйте страницы в нужную папку закладок Chrome, не отрывая рук от клавиатуры.

**English:** Save pages to the right Chrome bookmark folder without reaching for the mouse.

**Для кого:** люди, которые регулярно сохраняют статьи, документацию и материалы для проектов в папки закладок Chrome. Первый сегмент для проверки — разработчики с большой коллекцией папок.

**Сценарий:** открыть Marky → ввести часть названия папки → нажать Enter. Если совпадений нет, можно создать новую папку и сохранить страницу в неё.

**Основания для доверия:** существующие закладки Chrome; без отдельного аккаунта и импорта; обработка расширением на устройстве; без аналитики и серверов Marky; открытый исходный код.

**Тон:** коротко и предметно. Показывать сохранение конкретной страницы в конкретную папку. Не обещать непроверенную экономию времени, не называть продукт уникальным или самым быстрым, не обещать поиск по сохранённым страницам — Marky фильтрует папки.

**Важные ограничения:** уже сохранённая страница переносится в выбранную папку; новые папки создаются в Панели закладок; создание доступно, когда фильтр не нашёл папок; сочетание клавиш может потребовать ручного назначения.

**Основной язык продвижения:** английский. Для русскоязычных сообществ — русская карточка и отдельные скриншоты с русскими подписями.
