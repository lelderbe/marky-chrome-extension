# Материалы Marky для Chrome Web Store

Первоначально подготовлены 11 октября 2026 года. Тексты, скриншоты и демонстрации обновлены 12 октября: главный акцент — быстрота и простота сохранения закладок мышью или с клавиатуры. Материалы используют текущую сборку с изменениями после версии 1.2.0. Публикация в магазине и загрузка видео на YouTube выполняются отдельно.

## Что готово

- `positioning.md` — аудитория, обещание и границы рекламных утверждений.
- `listing/en.txt`, `listing/ru.txt` — полные описания для вставки в Developer Dashboard.
- Названия и короткие описания — в `public/_locales/en/messages.json` и `public/_locales/ru/messages.json`. Короткие описания укладываются в 132 символа.
- `assets/en/01-save.png`, `02-filter.png`, `03-create.png` — английские скриншоты 1280×800, в порядке размещения в магазине.
- `assets/ru/01-save.png`, `02-filter.png`, `03-create.png` — русские скриншоты 1280×800.
- `assets/promo-small.png` — общая промокартинка 440×280.
- `assets/en/demo.mp4`, `assets/ru/demo.mp4` — короткие демонстрации без звука.
- `assets/en/demo.gif`, `assets/ru/demo.gif` — версии для README и публикаций.
- `preview.html` — просмотр всех материалов и видео.
- `release/marky-extension.zip` в корне проекта — текущая сборка расширения с обновлёнными текстами. Архивы выпущенных версий сохранены отдельно как `release/marky-extension-1.2.0.zip` и `release/marky-extension-1.1.1.zip`.

## Происхождение изображений и видео

В сценах используется настоящий собранный интерфейс Marky из `dist/`, без переписывания его компонентов. Для браузерного предпросмотра Chrome API заменены адаптером с демонстрационными папками и страницей. Личные закладки не читаются и не меняются. Браузерная рамка и фоновая статья — иллюстрация контекста; подписи и подсказки о нажатых клавишах находятся за пределами интерфейса расширения.

Видео смонтировано из кадров работы интерфейса и действий с демонстрационными данными. Это иллюстрация сценария, а не замер производительности и не непрерывная запись пользовательского браузера.

## Порядок публикации

1. Загрузить `release/marky-extension.zip`: новый заголовок и короткое описание берутся из манифеста. Начиная с версии 1.1.1 расширение поддерживает русский язык, чтобы он появился в выборе локалей карточки.
2. В английской локали вставить `listing/en.txt`, заменить три скриншота файлами из `assets/en/`.
3. В русской локали вставить `listing/ru.txt`, добавить три скриншота из `assets/ru/`.
4. Заменить малую промокартинку файлом `assets/promo-small.png`. Она общая для всех языков.
5. При желании загрузить готовые MP4 на свой YouTube-канал с доступом по ссылке или публично и вставить ссылки в поля промовидео соответствующих локалей. Магазин принимает ссылку на YouTube, а не MP4-файл.
6. Сверить черновик и отправить на проверку. После публикации проверить обе языковые карточки.

## Повторное создание в репозитории

`npm run build` собирает интерфейс. `node marketing/tools/serve.mjs` открывает локальный предпросмотр на `http://127.0.0.1:4178/marketing/preview.html`; сцены для захвата — `/marketing/tools/scene.html?lang=en&scene=save` (или `filter`, `create`, `intro`, `outro`, язык `ru`). Готовые кадры лежат в `marketing/captures/` (не входят в Git). В `tools/` сохранены исходники сцен и сборки видео.

Обновлённую панель можно проверить на `/marketing/tools/popup-preview.html`: первый запуск, сохранённая страница, отсутствие горячей клавиши, ошибки с повтором, медленное сохранение и длинный список папок. Доступны русский и английский языки, светлая и тёмная темы. Этот предпросмотр использует текущую сборку. Изображения и видео в `assets/` пересняты с обновлёнными текстами 12 октября 2026 года; при следующих изменениях интерфейса их нужно обновлять отдельно от сборки расширения.

## Проверенные требования магазина

- Короткое описание: до 132 символов.
- Скриншоты: PNG 1280×800, без прозрачности; три на локаль.
- Малая промокартинка: 440×280, общая для локалей.
- Видеополе: ссылка YouTube.
- Русская локаль требует `_locales/ru/messages.json` в опубликованном пакете.
